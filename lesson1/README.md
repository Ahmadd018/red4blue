# Lesson 1 — Reconnaissance, Initial Access & Phishing

**Duration:** 2 hours  
**Format:** Kali (attacker) vs Windows (victim) on the same LAN

## Files

```
lesson1/
├── GUIDE.md              ← start here — full 2-hour walkthrough
├── setup/
│   └── setup_lab.sh      ← run once before class
├── tools/
│   ├── http_server.py    ← attacker payload/credential server
│   ├── smtp_server.py    ← fake SMTP relay for GoPhish
│   ├── beacon.py         ← C2 check-in simulator (run on victim)
│   └── create_macro_doc.py
├── templates/
│   ├── phishing_email.html   ← paste into GoPhish email template
│   └── fake_login.html       ← paste into GoPhish landing page
└── payloads/
    ├── calc_payload.ps1      ← benign Windows payload (opens calc)
    ├── downloader.ps1        ← PowerShell download cradle demo
    └── macro_code.vba        ← VBA macro (generated by create_macro_doc.py)
```

## Quick Start

```bash
git clone https://github.com/<your-org>/red4blue.git
cd red4blue/lesson1
sudo bash setup/setup_lab.sh
# then open GUIDE.md
```

## Topics Covered

- Passive OSINT: whois, DNS, crt.sh, theHarvester, Shodan, Google Dorks
- Active recon: nmap host discovery, port scan, OS detection
- Phishing campaign: GoPhish end-to-end (sending profile → email → landing page → results)
- Site cloning: wget / httrack
- Macro document: VBA AutoOpen technique
- PowerShell download cradles (WebClient, IWR, certutil, fileless IEX)
- C2 beacon simulation
- Evilginx2 AiTM (session cookie theft, MFA bypass)
- Blue team: firewall logs, Wireshark, Event IDs 4104/4688, artifact hunting
